
# Репозиторий `main`

Основной репозиторий проекта сайта **Sauto.md**.  
Содержит актуальную рабочую версию сайта, которая публикуется на основном домене:  
**https://sauto.md**

---

## Назначение

- Это стабильная, проверенная версия проекта.
- Все изменения попадают сюда только после тестирования в ветке `dev`.
- Этот репозиторий связан с боевым сайтом и должен оставаться чистым и надёжным.

---

## Деплой и уведомления

- Каждый коммит в ветке `mine` автоматически разворачивается на основном домене.
- Влад (маркетолог) получает уведомления о каждом обновлении по e-mail.

---

## Порядок работы

1. Разработка и тест — в ветке `dev` (в другом репозитории)
2. Проверка на `testline8392.sauto.md`
3. После одобрения — перенос в `mine` (здесь)
4. Ветка `mine` автоматически деплоится на **sauto.md**

---

## Защита

- Ветка `mine` защищена от прямого редактирования.
- Только проверенные изменения после теста в `dev`.
