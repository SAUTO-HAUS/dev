# Репозиторий `dev`

Тестовый репозиторий для работы над сайтом компании Sauto.md.  
Используется для отладки, доработок, временных изменений и тестов перед публикацией на основном сайте.

---

## 📂 Структура

- `dev` — эта ветка используется для внесения и тестирования изменений. Автоматически деплоится на:
  **https://testline8392.sauto.md**

- `main` — основная рабочая ветка. После ручной проверки изменения из `dev` вливаются сюда и публикуются на основном домене.


## 🚀 Автоматический деплой

Каждый коммит в ветке `dev` автоматически разворачивается на поддомене:
**https://testline8392.sauto.md**

В этой среде разработчики и маркетологи могут видеть изменения вживую и проводить тестирование.

---

## 📬 Уведомления

О каждом коммите и изменении в ветке `dev` уведомление отправляется на корпоративный e-mail маркетинговой команды.

---

## 🤖 robots.txt

На тестовой версии сайта (`testline8392.sauto.md`) автоматически установлен `robots.txt` с запретом индексации поисковыми системами.
---

## 🧱 Защита ветки

Ветка `dev` может быть защищена:
- от force push
- от удаления
- или с обязательным review

> ⚠️ Настройки защиты обсуждаются отдельно и могут быть применены при необходимости.
---

## 🔁 Порядок работы

1. Разработчик вносит изменения в ветку `dev`.
2. Изменения деплоятся на тестовый поддомен.
3. Маркетологи и команда проверяют результат.
4. После одобрения создаётся Pull Request в ветку `mine`.
5. Ветка `mine` деплоится на боевой сайт.

---

## 📎 Примечания

- Репозиторий **приватный**. Сторонние лица не имеют доступа.
- Telegram-уведомления **не настроены**.
- Все изменения в `main` должны быть стабильны. Прямой коммит в `main` без проверки — **не допускается**.
