# Система разграничения прав доступа (RBAC) - Документация

## Обзор реализации

Была реализована комплексная система разграничения прав доступа пользователей в административной панели сайта с поддержкой ролей и филиального доступа.

## Роли пользователей

### 🔑 Gordon (Суперадминистратор)
- **Полный доступ** ко всем разделам административной панели
- Управление пользователями и их правами
- Удаление и восстановление автомобилей
- Доступ ко всем филиалам
- Настройки сайта, SEO, структура, интеграции
- Управление ролями других пользователей

### 👨‍💼 Admin (Администратор)
- Почти полный доступ, за исключением управления пользователями
- Добавление, редактирование, удаление автомобилей
- Управление карточками товаров
- Доступ ко всем филиалам
- **Не может** менять роли других пользователей или настраивать доступы

### 📝 Publisher (Публикатор)
- Заливка автомобилей
- Редактирование и публикация на сайте
- **Не имеет доступа к удалению**, но может отмечать "не в наличии"
- Работает с **обоими филиалами**

### 🏢 Publisher-Limited (Публикатор Филиал)
- Те же права, что и Publisher
- **Ограничен одним филиалом** (например, только Calea Moșilor или второй филиал)
- Не видит автомобили других филиалов
- Не может редактировать чужие записи

## Структура базы данных

### Новые поля в таблице `_adm_usr`:
- `role` - новая роль пользователя (gordon, admin, publisher, publisher_limited)
- `branch_id` - привязка к филиалу (для Publisher-Limited)
- `permissions` - дополнительные права (JSON)
- `created_at`, `updated_at` - временные метки

### Новые таблицы:
- `_branches` - филиалы компании
- `_roles` - роли с описанием и правами
- `_permissions` - детализированные права доступа

### 3. Обновленные файлы:
- `content/admin/action/adm_chk.php` - добавлена поддержка новых полей ролей

## Функциональность

### ✅ Реализовано:
1. **Система ролей** с настраиваемыми правами доступа
2. **База данных** для хранения ролей, филиалов и прав
3. **PHP класс RBAC** для проверки прав доступа
4. **Интерфейс управления ролями** в админке (только для Gordon)
5. **Фильтрация меню** согласно ролям пользователей
6. **Проверка доступа** к разделам на уровне backend
7. **Поддержка филиального доступа** для Publisher-Limited

### 🔄 В процессе:
1. Ограничение доступа к разделам админки согласно ролям
2. Фильтрация данных по филиалам в каталогах
3. Полное тестирование всех ролей

## Использование

### Назначение роли пользователю:
1. Войти в админку под учетной записью Gordon
2. Перейти в Настройки → Управление ролями
3. Выбрать пользователя и назначить роль
4. Для Publisher-Limited выбрать филиал

### Проверка прав в коде:
```php
// Подключение RBAC
require_once(_ADM_INCL.'/rbac_config.php');

// Проверка права на действие
if (rbac_has_permission($user_role, 'cars', 'delete')) {
    // Пользователь может удалять автомобили
}

// Проверка доступа к филиалу
if (rbac_can_access_branch($user_role, $user_branch_id, $target_branch_id)) {
    // Пользователь может работать с этим филиалом
}
```

## Безопасность

- Все проверки прав выполняются на стороне сервера
- Меню фильтруется согласно ролям пользователя
- Доступ к страницам проверяется через RBAC
- Publisher-Limited видит только свой филиал
- Gordon имеет полный контроль над системой ролей
